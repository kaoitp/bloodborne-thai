# ตารางวิจัยศัพท์ Bloodborne

เทียบคำที่ผู้เล่นเห็นในม็อด `v1.0.2` กับต้นฉบับอังกฤษ (UK) ของ Bloodborne CUSA03173 v1.09 โดยดูฉบับญี่ปุ่นและคำอธิบายในเกมประกอบเมื่อศัพท์แปลได้หลายทาง คอลัมน์ «ข้อเสนอหลังวิจัย» เป็นคำเสนอใช้ในม็อด บางคำเสนอให้คงรูปเดิมไว้

ทะเบียนอ้างอิงใช้รูป `ตาราง / ID` ตรวจย้อนกลับได้จาก `source/en/` และ `source/ja/` ที่สกัดจากสำเนาเกมในเครื่อง สำหรับคำแปลปัจจุบัน ให้ดู `th/` ที่รหัสเดียวกัน หากม็อดเว้นรหัสไว้ เช่น ชื่อหลายรายการใน `item.10` เกมจะแสดงชื่ออังกฤษจากต้นฉบับ ดูหลักการที่ม็อดใช้อยู่ใน [คู่มือศัพท์](terminology.md)

ทีมสร้างอธิบายโลกของเกมว่ามีกลิ่นอายวิกตอเรียนกอทิก มีทั้งการรักษา พิธีกรรม และความสยองที่โยงกับจักรวาล แนวทางในตารางจึงให้ชื่อทางพิธีกรรมมีน้ำเสียงตามโลกของเกม ใช้คำบอกผลให้ชัดในเมนูต่อสู้ และเก็บชื่ออังกฤษไว้คู่คำไทยเมื่อคนเล่นต้องใช้ค้นคู่มือ [บทสัมภาษณ์ทีมดนตรี Bloodborne](https://blog.playstation.com/2015/05/18/the-story-behind-bloodbornes-haunting-soundtrack/) · [หลักเกณฑ์การทับศัพท์ของสำนักงานราชบัณฑิตยสภา](https://www.orst.go.th/iwfm_list.asp?i=0040002104011001%2F63ERJ5716056)
