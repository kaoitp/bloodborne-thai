# สคริปต์จากรอบปรับคำแปลก่อนหน้า

ไฟล์ในโฟลเดอร์นี้บันทึกวิธีปรับคำและตรวจผลในแต่ละรอบ สคริปต์แก้คำจะเขียนทับไฟล์ใน `th/` และบางตัวอ้างอิงโครงสร้างตาราง ไฟล์ตารางทำงาน หรือ ZIP ของรุ่นที่ใช้ตอนนั้น ให้ดูรอบงานที่อ้างถึงในสคริปต์และทดลองบนสำเนาก่อนรัน

สำหรับการแก้คำแปลปัจจุบัน ให้แก้ JSON โดยตรงแล้วทดสอบด้วย `tools/install.py` ตาม [คู่มือหลัก](../../README.md#แก้คำแปลและสร้างตัวติดตั้ง) เก็บไฟล์เกมและข้อความอ้างอิงที่สกัดจากเกมไว้ในเครื่อง
